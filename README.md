# FiendGetConfigured

## Description

A configurable behavior addon for **AuroraBytes-The_Fiend 1.1.6** in Lethal Company.


## Features

- Configure walking, stalking, chasing and rage movement speeds.
- Configure damage, execution HP threshold, contact range, attack cooldown and normal-hit knockback.
- Require visibility before acquiring players. After losing sight, search the last seen position for a configurable time instead of following a hidden player's current position.
- Configure detection range and field of view.
- Toggle random teleports, apparatus rage, temporary rage, door breaking and breaker-box destruction.
- Configure or disable the late-game speed and random-ability boost.
- Enforce the modern Fiend behavior while this addon is enabled.
- Enforce the attack cooldown on the server, including repeated contact requests.


## Technical Details

- Developed for Lethal Company v81 and AuroraBytes-The_Fiend 1.1.6


## Installation

- Install **FiendGetConfigured on every player**, with the **same version and configuration**. There is no automatic config synchronization.
- A mod manager installs the dependencies automatically. For manual installation, place `FiendGetConfigured.dll` under `BepInEx/plugins/FiendGetConfigured/`.
- Restart the game after changing the configuration.

The separate config is generated on first launch:

```text
BepInEx/config/TranslationLookasideBufferModding.FiendGetConfigured.cfg
```

### Defaults

| Setting | Default |
|---|---:|
| Walking speed | 3 |
| Stalking speed | 1 |
| Chase speed | 5.5 |
| Rage speed | 7 |
| Normal hit damage | 25 |
| Execution threshold, HP before the hit | 25 |
| Contact attack distance, meters | 2 |
| Minimum attack cooldown, seconds | 2 |
| Normal-hit knockback | 15 |
| Require line of sight | true |
| Detection range, meters | 30 |
| Full field of view, degrees | 140 |
| Last-seen memory, seconds | 8 |
| Random teleport | false |
| Apparatus rage | false |
| Temporary rage | false |
| Door breaking | true |
| Breaker-box destruction | true |
| Late-game boost | false |

With 100 HP and no other damage modifiers, the defaults allow three 25-damage hits, followed by a lethal grab on the fourth accepted attack. Set `ExecutionHealthThreshold = -1` to disable the execution grab; ordinary damage can still kill.

Spawn weight, moon filters, flicker chance and sound volume remain controlled by the original mod's **`com.TheFiend.cfg`**.
